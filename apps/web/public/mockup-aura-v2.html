🎨 O que muda no Aura Design v2

Botões

• Altura padrão 52px (4 × 13px)
• Border-radius 6.5px — mais preciso
• Border 1.5px solid tonal
• Shadow nectarine + scale hover

Inputs

• Altura 52px padrão Aura
• Ícone contextual interno
• Focus ring nectarine (outline 3px)
• Border-radius 6.5px consistente

Ícones

• 20px × strokeWidth 1.5 universal
• Cor semântica por contexto
• Badge colorido nos atalhos
• Ícones dentro dos inputs

Tipografia

• Line-height 1.21 Aura nativo
• optimizeLegibility ativo
• Labels 10px / 700 / tracking
• Hierarchy mais clara h1→label

Cards / Textura

• Glass rgba(255,253,249,.82)
• Border rgba(255,255,255,.68)
• Border-radius 18–20px
• Shadow tonal nectarine

Linhas

• Divider 1px var(--warm-border)
• Planner blocks 4px left border
• Input border 1.5px tonal
• Focus ring 3px nectarine soft
