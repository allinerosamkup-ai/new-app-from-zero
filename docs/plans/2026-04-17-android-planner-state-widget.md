# Android Planner State Widget Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build one Android home screen widget for the Airia APK that shows today's state and upcoming planner blocks.

**Architecture:** Keep the Expo app managed by adding a config plugin that writes native Android widget files during prebuild/EAS. React Native writes a compact widget summary to local storage whenever Home loads planner/check-in data, and the Android `AppWidgetProvider` renders that summary through `RemoteViews`.

**Tech Stack:** Expo SDK 51, React Native 0.74, TypeScript, Android AppWidgetProvider, Kotlin, XML RemoteViews, AsyncStorage/SharedPreferences.

---

### Task 1: Add Widget Data Mapper

**Files:**
- Create: `apps/mobile/src/widgets/todayWidgetData.ts`
- Modify: `apps/mobile/src/presentation/screens/HomeScreen.tsx`

**Steps:**
1. Create a small mapper that accepts `todayCheckin` and `blocks`.
2. Keep only serializable, non-sensitive data: state label/type, mood, energy, updatedAt, and up to three planned blocks.
3. Persist the JSON under `airia_widget_today` using `@react-native-async-storage/async-storage`.
4. Call the publisher from `HomeScreen` after planner/check-in state changes.

### Task 2: Add Android Widget Config Plugin

**Files:**
- Create: `apps/mobile/plugins/withAiriaTodayWidget.js`
- Modify: `apps/mobile/app.json`

**Steps:**
1. Use `withAndroidManifest` to register `pro.airia.app.widget.AiriaTodayWidgetProvider`.
2. Use `withDangerousMod` to write Kotlin and XML files into the generated Android project.
3. Add the plugin to `expo.plugins` in `app.json`.

### Task 3: Generate Native Android Widget Files

**Generated by plugin:**
- `android/app/src/main/java/pro/airia/app/widget/AiriaTodayWidgetProvider.kt`
- `android/app/src/main/res/layout/airia_today_widget.xml`
- `android/app/src/main/res/xml/airia_today_widget_info.xml`
- `android/app/src/main/res/drawable/airia_widget_background.xml`
- `android/app/src/main/res/values/airia_widget_colors.xml`

**Steps:**
1. Render a 4x2 widget with title, state, updated text, and three planner rows.
2. Use `RemoteViews`, no Compose/Glance dependency.
3. Add click intent to open `MainActivity`.
4. Read data from shared preferences defensively and show empty states when absent.

### Task 4: Validate

**Commands:**
- `npx tsc -p apps/mobile/tsconfig.json --noEmit`
- `npx expo config --type introspect`

**Expected:**
- TypeScript passes.
- Expo config includes the Android widget plugin without config errors.
