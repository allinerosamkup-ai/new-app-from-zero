# Células

Fonte canônica completa: `docs/product/MULTIAGENT_GOVERNANCE.md` §4.

Rotas: `/comecar` `/checkin` `/home` `/goals` `/insights` `/journal` `/aura` `/preferences`.

Cada página: funcionalidade + UI/UX + verificador que **não** é o autor.
O coordenador **não** reescreve o trabalho da célula por preferência.
O integrador monta a versão aprovada; **não** inventa funcionalidade.

| Célula | Pergunta de sucesso |
|---|---|
| Onboarding / Pra começar | A pessoa chega à primeira Home com algo útil já construído? |
| Check-in e resultado | A pessoa consegue registrar o estado e entender o que muda agora? |
| Home / Hoje | Em poucos segundos fica claro o que fazer agora? |
| Objetivos | A ação atual é realmente executável para aquele objetivo? |
| Padrões | A pessoa aprende algo útil sem ser induzida a uma conclusão falsa? |
| Diário | A pessoa sente que foi ouvida e controla o que vira ação? |
| Airia central | A conversa produziu uma ajuda verificável, não só texto? |
| Configurações | A pessoa consegue ajustar o que importa sem se perder? |

Contrato de entrada/saída: brief → código, testes, registro de UI/UX, impactos, evidências, reversão. Parecer local com nota é obrigatório e não pode ser do autor.
